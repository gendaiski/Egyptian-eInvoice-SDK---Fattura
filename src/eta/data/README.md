# ETA code tables

JSON snapshots of the code lists published in the ETA eInvoicing SDK
(`/codes/tax-types`, `/codes/unit-types`, `/codes/activity-types`, `/codes/country-codes`, `/codes/currencies`).

Source: [mrkindy/EgyptianEInvoice](https://github.com/mrkindy/EgyptianEInvoice) `src/Data/`,
MIT License, Copyright (c) 2022 Ibrahim Abotaleb. Minified, contents unchanged.

These are the offline seed. In production the admin *Reference data* job re-syncs them from the
SDK nightly, so treat this folder as a fallback, not the source of truth.
