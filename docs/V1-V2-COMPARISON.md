The [branch comparison](https://github.com/gendaiski/Egyptian-eInvoice-SDK---Fattura/compare/claude/fatura-frontend...codex/fattura-egypt-v2) is the source for changed-code claims.

## Scope and interpretation

- V2 is an **incremental review build** of Fattura. It should not be counted as a new payment engine, new ETA SDK, or a verified live ETA integration.
- The separate **Meridian M&A Diligence System** lives in Sandbox-2 and is **not** inside Fattura v2. See the [v2 handover](V2-HANDOVER.md).
- For a visual review, start with the [v2 landing](v2-frontend-evidence/landing-light.png), [v2 dashboard](v2-frontend-evidence/dashboard-light.png), and [v2 composer](v2-frontend-evidence/composer-desktop.png). This repository does not yet contain matched v1 screenshots, so the table's v1 visual claims are based on the v1 source diff rather than a side-by-side screenshot test.
